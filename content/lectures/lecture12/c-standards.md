The C programming language has evolved over time and has gone through many versions.

## At the beginning (1972)

- C was not standardized at all 
- There was no offical documentation.
- The equivalent of a standard was provided by the creators of "C" in the first edition of <strong>The C Programming Language by Dennis Ritchie and Brian W. Kernighan</strong> in 1978. Early versions of C are often referred to as <strong>K&R</strong> "C" in reference to the original creators.

## ANSI C (1989)

ANSI introduced X3.159-1989 "Programming Language C" widely called ANSI C. It is also sometimes referred to as C89. 

?? This is the version we are using in this course ??

<info>
    ANSI C is the foundation for every version of C that came after it. Every ANSI C program can be compiled and run in any version of C that has come after. The standardization of C has a heavy focus on backwards compatibilty since a lot of critical software was written in old versions, and migrating to newer versions is sometimes not possible or pratical.
