## Instructions

Complete this mock midterm in the same conditions as you would a real exam.
For the best learning experience, I would recomended:
- Study the relavent material <strong>before</strong> attempting the mock midterm
- Don't use a device to look up questions
- Start a timer or keep track of time to get a feel for how you work on a time constraint
- Figure out what topics/concept you need to work on for the real exam

- <strong>Part A</strong>: 25 multiple choice questions
- <strong>Part B</strong>: 10 short code questions (Fill in the blank, identify errors, write small amounts of code, etc) 
- <strong>Part C</strong>: 5 longer code questions (write a function, draw a diagram of code execution, etc)
